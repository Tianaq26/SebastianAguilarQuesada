About me
Builder by instinct, developer by choice.

My main focus is game development and software engineering, but I also work with 3D modeling, shaders, VFX, robotics, and hardware. I'm the kind of person who, when faced with a problem I don't know how to solve, just goes and learns how to solve it.

Next step: university abroad. I'm looking for environments where ambitious builders can grow fast, work on hard problems, and make real things.

⭐ Flagship project
Eteria
// also known as Dragones de Valkar

An open-world RPG developed solo in Unity over two-plus years. Eteria features five islands with distinct biomes, a full dragon system with capture, taming, and rideable flight, turn-based elemental combat, AI-driven NPCs, handcrafted 3D assets, and a complete UI system — all running stably on low-end hardware.

This project is the clearest demonstration of what I can do: sustain a large, multi-system codebase over time, learn new technologies as needed, and deliver something polished. The same project that won Gold at both national and Iberoamerican Infomatrix.
